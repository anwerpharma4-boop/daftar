# دفتر (Daftar)

تطبيق مجاني ومفتوح المصدر لتدوين الملاحظات بالقلم، يعمل على **أندرويد** و **iOS / iPadOS**.
بُني بـ Flutter، وكل خصائصه متاحة دون اشتراكات أو مشتريات داخل التطبيق.
الترخيص: MIT.

## الخصائص الحالية

| الخاصية | التفاصيل |
|---|---|
| مكتبة الملاحظات | مواضيع ملوّنة في شريط جانبي (أو قائمة منسدلة على الهاتف)، وشبكة معاينات للصفحات، وبحث، وترتيب، ونقل، ونسخ، وحذف |
| الكتابة اليدوية | قلم يتأثر بضغط القلم، وقلم تظليل، وممحاة، وألوان ومقاسات متعددة، وتراجع وإعادة |
| رفض راحة اليد | عند استخدام القلم لأول مرة: الكتابة تتم بالقلم فقط، والإصبع يمرّر الصفحات (ويمكن تغيير ذلك من القائمة) |
| النصوص | إضافة مربعات نص في أي مكان، وسحبها وتعديلها، مع دعم كامل للعربية |
| أنواع الورق | فارغ، ومسطّر، ومربعات، ونقاط |
| ملفات PDF | استيراد PDF والكتابة فوق صفحاته |
| تسجيل الصوت | تسجيل المحاضرة أثناء الكتابة، ثم **إعادة التشغيل متزامنة مع الكتابة**: الحبر الذي لم يُكتب بعد يظهر باهتاً حتى يصل إليه التسجيل |
| التصدير | تصدير الملاحظة كملف PDF ومشاركتها |
| الحفظ | حفظ تلقائي على الجهاز، ولا يحتاج إلى إنترنت أو حساب |

## خصائص مخطّط لها

- أداة التحديد الحر (lasso) لنقل الكتابة وتغيير حجمها
- الأشكال الهندسية التلقائية
- التكبير والتصغير بإصبعين
- البحث داخل الخط اليدوي (التعرّف على الكتابة)
- المزامنة السحابية (مثل WebDAV أو Google Drive أو iCloud)
- عند لمس كلمة مكتوبة، ينتقل التسجيل إلى لحظة كتابتها
- إدراج الصور والملصقات

## التشغيل

### 1. تثبيت الأدوات
- [Flutter](https://docs.flutter.dev/get-started/install) (الإصدار 3.27 أو أحدث)
- لبناء نسخة أندرويد: Android Studio (يعمل على Windows و Mac و Linux)
- لبناء نسخة iPhone و iPad: جهاز **Mac** عليه Xcode (هذا شرط من Apple)

### 2. إعداد المشروع (مرة واحدة فقط)
على Windows:
```powershell
.\setup.ps1
```
على Mac أو Linux:
```bash
bash setup.sh
```
يقوم السكربت بإنشاء مجلدَي `android/` و `ios/`، ويضيف صلاحية الميكروفون، ثم ينزّل المكتبات المطلوبة.

### 3. التشغيل
```bash
flutter run
```

## هيكل الشيفرة

```
lib/
  main.dart                  تشغيل التطبيق، واللغة العربية، والثيم
  models.dart                الملاحظة، والصفحة، والخط، والنص، والتسجيل، والموضوع
  storage.dart               الحفظ على الجهاز (ملفات JSON)
  screens/library_screen.dart  المكتبة
  screens/editor_screen.dart   محرر الصفحات والأدوات والصوت
  services/pdf_import.dart     استيراد PDF
  services/export.dart         تصدير PDF والمشاركة
  widgets/                   رسم الورق والحبر، والألوان، ونوافذ الحوار
```
